# VoiceBox

Complaint and Suggestion Management System

VoiceBox is a web-based and mobile application complaint and suggestion management system developed for Lourdes College TVL students.

The system allows students to submit complaints, suggestions, concerns, and feedback online. It also allows users to track their submissions while authorized personnel can review and manage them through the system.

Website: https://voicebox.sbs/


## About the Project

VoiceBox was developed as a TVL-ICT capstone project at Lourdes College.

The purpose of the system is to provide students with an easier and more accessible way to submit complaints and suggestions without depending only on paper forms or face-to-face communication.

Students can access VoiceBox using the website or the Android application.


## Main Features

- Submit complaints
- Submit suggestions
- Track submitted complaints and suggestions
- User accounts and profiles
- Submission status updates
- Web portal
- Android application
- Administrative dashboard
- User management
- Complaint and suggestion management
- Public submission statistics
